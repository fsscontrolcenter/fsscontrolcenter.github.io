FSS Control Center

Welding Department — aplikasi pengolahan Data FSS, SCH Update, dan Tanpa Rumus.

Frontend dan halaman informasi tersedia melalui GitHub Pages. Pengolahan Excel berjalan di laptop Windows masing-masing pengguna.

Download Launcher Windows

Cara menggunakan

  1. Download dan ekstrak ZIP Launcher.
  2. Jalankan FSSControlCenter.exe.
  3. Tunggu sampai status backend aktif dan browser terbuka.
  4. Gunakan aplikasi. File Excel diproses di laptop ini.
  5. Tutup jendela Launcher untuk menghentikan aplikasi.
Fitur SCH Update dan beberapa proses Tanpa Rumus yang memakai xlwings memerlukan Microsoft Excel desktop terpasang di Windows.
